# Decisions

- D001: Both drawings are sections of B03 Ground Floor, never separate floors.
- D002: Use native PDF vector extraction and explicit affine transforms; rendering PNGs is for QA only.
- D003: Evidence gates geometry and navigation. Uncertain outlines, doors, scale, kiosk placement and accessibility remain unknown/candidate.
- D004: Canonical contract uses normalized 2D master coordinates and separates content, semantic geometry and graph.
- D005: Next.js/React/TypeScript and orthographic React Three Fiber; static JSON data initially, replaceable adapters later.
- D006: Browser SpeechSynthesis is behind TTSService, with honest unsupported/language-voice states.
- D007: Agent ownership is exclusive. Independent QA reviews features it did not author. Source unknowns must be distinguished from implementation defects.
- D008: Six text anchors and 474 coincident architectural primitives establish the sheet translation (+1033.29,-28.35); the shared coordinate frame retains the source viewBox origin.
- D009: The schedule provides 54 stable directory entries; source-name/code conflicts persist in provenance and review records. Candidate contours are visually distinguished, unresolved contours use markers.
- D010: Routes are fail-closed on unconfirmed nodes/edges, unknown restrictions, obstacles, out-of-area geometry, and inconsistent floor metadata. A positive synthetic test is not a verified B03 route.
- D011: Next 16.3.5 / React 19.2.8 and Vitest 4.1.11 selected after dependency compatibility/security checks; lockfile records installed versions.
- D012: Source processing uses a repository-local Python virtual environment with pinned direct dependencies. The browser map rasterizes the already-extracted SVG only as a rendering texture; source ingestion and semantic extraction remain vector-based, with no raster tracing.
- D013: User revision enables explicit drawing-based planning. Candidate geometric provenance and current access confirmation are separate; computationally valid source routes no longer require a blanket administrative gate. Closed links, invalid geometry and unknown accessibility under the accessible-only filter remain excluded.
- D014: The source Main Entrance is a named planning default, not an inferred physical kiosk. Room notes and partial flags qualify suite/perimeter and exterior endpoints; never relabel an approach as exact arrival.
- D015: Orthographic room meshes use visible illustrative height, textured tops, shaded sides and rims. Circulation stays low so routes remain legible; no full viewBox slab is presented as a building footprint.
